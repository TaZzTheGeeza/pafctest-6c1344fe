# Homework Feature Coach Video

## Goal
Create a short 16:9 video for coaches using real screenshots from the live Homework feature, with one clear AI-narrated line matched to each screen.

## What I’ll make
- Capture the real coach Homework builder, question sheet, YouTube preview, submissions/feedback, and Star of the Week screens.
- Build a concise black-and-gold PAFC walkthrough, approximately 45–60 seconds.
- Use separate narration clips per scene so no voices overlap and every line describes the screen currently shown.
- Add subtle zooms and highlights to direct attention without hiding the real interface.
- Export and verify a high-quality MP4 in Files.

## Creative direction
- **Style:** Broadcast-style PAFC product walkthrough; dark, confident, practical.
- **Palette:** Deep black `#050505`, PAFC gold `#C9A84C`, off-white `#F5F1E8`.
- **Type:** Oswald-style condensed display text with a clean sans-serif body.
- **Motion:** Slow screenshot pans, gold focus lines, clean wipes, no flashy effects.
- **Story:** Create homework quickly → add learning material → review evidence → encourage players.

## Technical details
- 1920×1080, 30fps, H.264 MP4.
- Real screenshots captured from the running app.
- Scene-specific voice tracks with timings based on actual audio duration.
- Final checks include key-frame review, audio-stream inspection, duration, and file size.
